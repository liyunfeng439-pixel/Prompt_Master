# V10.1.2 Runtime Governance

## Current authority
The only current execution authority is V10.1.2.

1. Entry: `SKILL.md`
2. Canonical runtime: `CANONICAL_RUNTIME_V10.1.2/RUNTIME_MASTER_CANONICAL_V10.1.2.yaml`
3. Shot budget: `CANONICAL_RUNTIME_V10.1.2/SHOT_BUDGET_CONTROLLER_V10.1.2.md`
4. Semantic contract: `CANONICAL_RUNTIME_V10.1.2/SHOT_IR_CONTRACT_V10.1.2.md`
5. Native output router: `NATIVE_OUTPUT_ROUTER_V10.1.2/router.yaml`
6. QA gate: `QA_V10.1.2/V10.1_REGRESSION_RULES.md`

## Runtime isolation
- No V7, V8, or V9 runtime file may act as a current execution authority.
- Historical runtimes and legacy output layers are stored under `LEGACY_RUNTIME_ARCHIVE/`.
- Legacy files are reference-only and cannot override current contracts.
- Active functional modules may retain historical names when they are knowledge/data modules; they must not declare themselves as the current runtime.

## 30-second shot budget
- Default target: 7 final shots.
- Soft minimum: 6.
- Hard maximum: 7.
- Beat Auto-Split never creates final shots by itself.
- S07 normally contains final impact, result lock, and ending observation.
- User-specified shot counts override the default only when explicitly requested.

## Output authority
`SHOT_IR` is the single semantic source. The V10.1 Native Output Router compiles it into Universal, Seedance 2.5, or MiniMax H3 output. Adapters may alter presentation but never combat semantics.

## Model-template naming
This package does not claim that internal Skill templates are vendor-official templates. Vendor-specific adapters are described as Skill-native compilation contracts unless verified official documentation is supplied by the user.
