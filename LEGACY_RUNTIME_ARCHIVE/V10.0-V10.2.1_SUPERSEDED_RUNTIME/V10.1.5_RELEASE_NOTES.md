# Combat Prompt Master V10.1.5

## V4 Action Knowledge Runtime Integration

Base: V10.1.4
Knowledge: V4.0

### Solved
- V4 knowledge is no longer passive data.
- V4 execution fields are resolved into ACTION_EXECUTION_CONTRACT.
- Combat State is bound before execution.
- Opponent response feeds next tactical state.
- Counter and recovery are conditional runtime states.
- V4 transition_contract is a hard transition gate.
- V4 camera/VFX/environment semantics are bound to causal events.
- Beat Graph only accepts validated V4 execution contracts.
- SHOT_IR retains V4 traceability metadata.

### Preserved
All existing V10.1.4 runtime, knowledge assets, model adapters, shot budget logic and QA remain in the package. No legacy asset was deleted.
