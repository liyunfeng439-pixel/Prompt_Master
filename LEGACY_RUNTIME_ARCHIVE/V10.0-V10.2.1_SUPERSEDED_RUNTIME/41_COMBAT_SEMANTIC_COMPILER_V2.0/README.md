# Combat Semantic Compiler V2.0 (V10.1.9)

Transforms one SHOT_IR into model-facing prompt text by selecting the highest-value visible combat semantics, suppressing repeated mechanics, compressing camera/VFX, and keeping all facts immutable.

Key functions:
- Action Semantic Feature Ranking
- Local + shot-level redundancy suppression
- Cinematic sentence synthesis
- Camera compression
- VFX compression
- Runtime term suppression
- Fact/Inference boundary preservation
- Universal / Seedance 2.5 / MiniMax H3 output
- Prompt semantic quality metrics
