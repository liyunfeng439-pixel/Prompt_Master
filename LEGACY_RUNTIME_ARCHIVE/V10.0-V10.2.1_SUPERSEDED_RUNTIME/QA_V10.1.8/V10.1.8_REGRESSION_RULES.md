# V10.1.9 Regression Rules

PASS requires:
- current authority metadata = 10.1.9
- Weapon integrity = 100%
- Outcome/result contract = 100%
- normalized state fields = 100%
- graph transition contract drift = 0
- 32 deep ability signatures = 32
- explicit recovery events for block/dodge/miss/bind outcomes in Harness
- non-empty unique Beat IDs
- 30s hard max = 7 shots
- final RESULT_LOCK and ending decision in final shot
- native prompt compiler emits actual prompt text for all enabled adapters
- all adapters derive from one SHOT_IR and share the same semantic fingerprint
- provenance is preserved; INFERRED is not silently promoted
- no attack event after RESULT_LOCK

FAIL if:
- a manifest is emitted without actual prompt text
- adapter only references SHOT_IR without compiling it
- event coverage differs across adapters
- Beat IDs are empty
- 8+ shots appear in a default 30s run
- any result lock is followed by a new attack event
