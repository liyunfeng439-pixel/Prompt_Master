# Combat Prompt Master V10.1.6

## Base
V10.1.5

## P0 repair
The V10.1.5 runtime stress test exposed a cross-layer weapon identity mismatch: 6300/10000 armed action records carried `weapon_control.weapon = 徒手` and corresponding prompt semantics inherited the wrong weapon label. V10.1.6 repairs those records and adds a mandatory integrity gate.

## Additional hardening
- All 10000 production actions now carry action-level transition contracts with weapon identity in pre/result states.
- Weapon identity is propagated into weapon-action, martial, motion-graph, action-graph and combo trace layers.
- Persistent/escalation abilities now require Ability Execution Contracts; `法相` has an explicit causal execution contract and result-lock/no-chase ending state.
- Current canonical authority paths are version-clean at V10.1.6.

## Preservation
This is an incremental build from V10.1.5. Existing files and assets were preserved; new authority layers are added rather than replacing the knowledge base with a smaller standalone rebuild.
