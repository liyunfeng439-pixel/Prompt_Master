# V10.2.1 Release Notes

## Upgrade from V10.2.0

### P0 — End-to-End Harness Timeout
Fixed by replacing subprocess-based compiler/QA orchestration with in-process calls and selected-action cache embedding. The parent no longer loads the full knowledge base and then launches child processes that reload it.

### Runtime Trace Memory Contract
`runtime_trace.selected_action_payloads` carries only the action records actually used by the test. This keeps the trace self-contained for Native Prompt Compilation without serializing all 10,000 actions.

### Fast Streaming Preflight
Added `TOOLS/validate_v1021.py` and `TOOLS/V10.2.1_CONTRACT_SNAPSHOT.json`. Standard Harness checks immutable file hashes without loading the 10k/18k datasets a second time.

### Deep QA in Process
Deep Prompt Semantic QA exposes `run_quality(prompts, runtime)` and is now called directly by the Harness.

### Compatibility
V10.2.0 Harness/Compiler/QA remain preserved. V10.2.1 is the sole current execution authority.
