# V10.2.0 Release Notes

## Base
Incremental build from V10.1.9. No prior relative-path file removed.

## Primary repair
V10.1.9 passed Runtime and sentence-level semantic QA, but its final prompts still reused the same motion mechanics, trajectories, contact descriptions and body-chain phrases across different actions. V10.2.0 treats this as a component-level semantic defect.

## Design rule
The compiler preserves decisive execution semantics, but does not expose every raw data field. It actively suppresses repeated low-value mechanics and prefers different valid components from the same execution contract.
