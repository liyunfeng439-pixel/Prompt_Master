# V10.1.6 Regression Rules

## PASS requires
- SKILL metadata = 10.1.6
- one canonical current runtime = V10.1.6
- current authority paths exist
- every current authority file declares V10.1.6
- 30s default hard_max_shot_count = 7
- Beat Auto-Split cannot increase final shot count
- Combat Director runs before Beat Graph
- Weapon Integrity runs before V4 resolution / tactical commitment
- Action Transition Validation runs before Beat Graph
- invalid physical/spatial/weapon transitions are rejected
- every production V4 action provides a transition contract
- all 10000 production actions pass weapon-binding equality checks
- all final shots compile from one V10.1.6 SHOT_IR contract
- Seedance 2.5 and MiniMax H3 use separate adapters
- adapters preserve invariant event/state fields
- legacy runtime files cannot override V10.1.6
- RESULT_LOCK cannot be changed by Ending Shot
- persistent/escalation abilities use ABILITY_EXECUTION_CONTRACT
- no unauthorized ability is treated as Canon

## FAIL if
- action.weapon differs from execution_model.weapon_control.weapon
- action.weapon differs from prompt_semantics.weapon_identity
- transition contract weapon identity differs from action weapon
- 30s output has 8+ final shots without explicit user instruction
- selected action cannot transition physically/spatially into next action
- shot compression hides required physical result
- ability result occurs without activation/manifestation causal chain
- RESULT_LOCK is mutated after final impact
- current authority points to a V10.1.4 runtime/compiler/router/QA path
