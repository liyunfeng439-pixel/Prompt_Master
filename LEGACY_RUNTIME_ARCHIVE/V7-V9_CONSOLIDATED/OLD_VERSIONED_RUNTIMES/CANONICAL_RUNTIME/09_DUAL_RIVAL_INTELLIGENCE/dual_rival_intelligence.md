# Dual Rival Combat Intelligence Runtime V7

## Purpose
将双角色战斗从动作排列升级为势均力敌的战斗博弈。

## Core Rule

双方不是：
Attack -> Receive Hit

而是：

Attack
→ Defense Analysis
→ Counter
→ Adaptation
→ Escalation

## Combat Balance Controller

默认规则：

- 双方主动攻击比例接近 50/50
- 单方连续压制不超过 3 Beat
- 每个优势阶段必须存在反制窗口
- 受击角色必须产生主动决策

## Rival Battle State

记录：

- 当前优势方
- 当前战术意图
- 已展示能力
- 已暴露弱点
- 可用反制方案

## Equal Power Battle Flow

Phase 1:
试探

Phase 2:
招式交换

Phase 3:
破解与反破解

Phase 4:
能力升级

Phase 5:
终极碰撞

## Anti Sandbag Rule

禁止：
- 一个角色连续输出
- 另一角色只闪避
- 无意义受击展示

必须：
- 双方至少一次主动突破
- 双方至少一次成功反制
- 双方至少一次战术调整
