# High-Impact Combat Runtime V6.8

## Purpose
将“高燃、打斗要帅、爽感强”转化为可执行的战斗选择优先级，而不是堆砌形容词或 VFX。

## Authority order
1. Immutable Canon / confirmed asset facts
2. Physical feasibility / spatial continuity / event causality
3. Tactical necessity / character combat DNA
4. Stylish Action Priority
5. Cinematic decoration

高燃偏好永远不能覆盖 1–3。

## High-Impact Action Priority
在硬过滤通过后，候选动作优先考虑：
- motion_amplitude：明显但可执行的身体与武器幅度
- acceleration_change：突发加速、急停、变向、反向借力
- contact_payoff：接触瞬间有清晰力量交换和结果
- displacement_payoff：命中/格挡后产生可见位移、失衡、错身或重新占位
- weapon_identity：动作能体现该武器独有的攻击包络和惯性
- combo_link_quality：能自然连接下一动作而不是孤立招式
- silhouette_readability：高速状态下仍能看清攻击线和身体轮廓
- camera_followability：镜头可以跟随原因，不依赖乱转、乱震掩盖动作
- environment_payoff：接触足够强时产生即时、持续的环境反馈

## Negative preferences
降低但不绝对禁止：
- 原地连续同类挥击
- 仅靠粒子/爆炸制造高潮
- 无结果的炫技翻滚
- 连续重复同一攻击平面
- 镜头旋转代替动作变化
- 只展示能力、不产生状态变化
- 为了“帅”而增加不属于角色/武器的动作

## Selection rule
多个候选均通过硬门槛时，优先选择高 Impact Payoff + 高 Style Fit + 高 Continuity Link 的方案；若两个方案视觉冲击相近，选择战术意义更强者。

## Beat requirement
每个主要战斗 Beat 至少应满足以下两项：
A. 明显运动变化；
B. 清晰接触/规避/借力；
C. 可观察状态结果；
D. 位移或空间关系变化；
E. 武器/能力辨识；
F. 环境反馈。
终极爽点通常应满足 3 项以上。
