# Ability / Power Runtime

Fantasy and supernatural abilities are simulated as causal events rather than decorative VFX.

Ability contract:
`activation → charge/preparation → cost/constraint → targeting → trajectory/area → contact → energy transfer → material/actor response → persistence → interruption/cooldown`

Required checks:
- activation condition
- range and targeting
- trajectory or area of effect
- contact/collision rule
- force/energy consequence
- interruption condition
- duration/persistence
- cooldown or reuse constraint when known

If an ability property is unknown, mark it UNKNOWN instead of inventing a hidden rule.
