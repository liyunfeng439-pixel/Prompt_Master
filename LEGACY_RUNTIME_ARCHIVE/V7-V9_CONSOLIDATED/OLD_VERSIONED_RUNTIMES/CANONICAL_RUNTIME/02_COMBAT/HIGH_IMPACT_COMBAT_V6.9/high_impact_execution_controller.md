# High-Impact Execution Controller V6.9

## Runtime order
`Hard Filter → Tactical Validity → Action Readability Gate → Stylish Action Priority → Complexity Budget → Beat Heat Check → Camera Followability → Auto-Split if needed → QA/Repair`

## Priority rule
1. Hard constraints / canon / physical feasibility
2. Tactical validity and event causality
3. Action readability
4. Stylish action preference
5. Complexity budget
6. Cinematic decoration

Stylish Action Priority cannot override readability or execution budget.

## Scoring rule
Recommended internal preference:
`style_score = weighted_style_features - repetition_penalty - complexity_penalty`

Readability is a gate, not a cosmetic bonus. Complexity beyond budget is a penalty, not a source of spectacle.

## Final-prompt compilation rule
Director/runtime annotations are compressed before final prompt output. Final prompt should preserve visible cause, motion, contact, force transfer, result, continuity and camera intent, while removing internal scoring jargon and redundant diagnostic prose.
