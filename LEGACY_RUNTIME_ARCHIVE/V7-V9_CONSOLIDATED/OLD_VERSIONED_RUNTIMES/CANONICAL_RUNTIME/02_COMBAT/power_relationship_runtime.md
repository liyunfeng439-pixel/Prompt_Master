# Power Relationship Runtime — 6.4

Resolve combat outcomes from relative capability rather than adjectives.

## Inputs
attack_power, defense_power, weapon_power, resistance, mass/stability, current_damage, contact_zone, angle, velocity, material_resistance, ability_state.

## Outcome classes
MISS, GLANCE, BLOCK, DEFLECT, ABSORB, STAGGER, KNOCKBACK, KNOCKDOWN, DISARM, BREAK, PENETRATE, WOUND, CRITICAL, DESTRUCTION.

Relative power may influence outcome, but never overrides geometry, contact or explicit canon.
