# Impact Outcome Taxonomy — 6.4

Every resolved contact chooses one explicit outcome class. Outcome must explain the next state.

`ATTACK + DEFENSE + POWER_RELATION + CONTACT_ZONE + CONTACT_GEOMETRY + MATERIAL/RESISTANCE -> OUTCOME -> STATE_DELTA`.

No generic `hit` is sufficient for a critical combat event. If outcome is unknown, propagate UNKNOWN and prevent downstream hard claims.
