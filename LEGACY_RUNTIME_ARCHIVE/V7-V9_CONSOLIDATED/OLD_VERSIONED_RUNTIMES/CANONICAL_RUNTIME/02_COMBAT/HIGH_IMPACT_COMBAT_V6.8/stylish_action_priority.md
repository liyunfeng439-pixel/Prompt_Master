# Stylish Action Priority V6.8

## Priority vector
`SILHOUETTE → ACCELERATION → CONTACT → FORCE_TRANSFER → DISPLACEMENT → RESULT → LINK`

这是视频模型可读性优先的动作表达顺序。

### Stylish action patterns
优先检索/组合：
- 高速贴身错身
- 兵器硬碰后借力变向
- 蹬地加速/急停反转
- 空中变线后落地追击
- 抓/卸/借/摔/闪/反击
- 枪杆/剑身/刀背等武器惯性参与的反击
- 攻击擦身后的即时回身追击
- 利用环境进行一次明确的空间转换

禁止把模板动作当作角色事实；必须通过动作库、角色战斗 DNA 或用户明确设定验证。
