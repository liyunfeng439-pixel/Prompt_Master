# Stylish Action QA V6.8

## PASS criteria
- 主要动作具有清晰 silhouette 和攻击线
- 高燃动作有实际接触/规避/力量交换或明确状态结果
- 镜头跟随事件原因，不用无意义旋转/震动制造速度
- 主要 Beat 不连续重复同一动作模板
- 战斗高潮由动作与结果产生，而非仅由 VFX 音量产生
- Tactical Pause 未超过默认上限，或有明确理由

## FAIL / repair
1. 先替换低表现力动作候选
2. 再增加位移/变向/接触结果
3. 再优化镜头跟随
4. 最后才增加 VFX/音频强调

不得通过增加爆炸、镜头抖动或慢动作掩盖动作本身不足。
