# Battle Blueprint Runtime — 6.4

Create the executable battle plan before individual actions.

## Required fields
narrative_goal, tactical_goal, emotional_goal, visual_goal, power_goal, pacing_goal, ending_goal, participants, arena, duration_budget, phases, escalation_curve, hard_constraints, forbidden_behavior.

## Phase planning
Each phase owns a purpose, approximate duration, intensity target, action density, impact density, recovery space and exit condition.

## Rule
Blueprint defines intent and budget, not final action facts. Actions remain subject to state, feasibility and tactical selection.
