# Combat Rhythm Curve — 6.5

Use time-varying `ACTION_DENSITY`, `IMPACT_DENSITY`, `MOVEMENT_DENSITY`, `CAMERA_DENSITY`, `DESTRUCTION_DENSITY` and `RECOVERY_SPACE`.

When `combat_first_pacing.enabled = true`, the default curve is biased toward immediate combat: `IMPACT/ENGAGEMENT → ACCELERATE → EXCHANGE → ESCALATE → PEAK → MICRO-RECOVERY → CLIMAX → ENDING_MODE`. Do not insert a long SETUP block unless explicitly required.

The first combat event is a pacing anchor. Character identification should preferably occur inside or adjacent to that event rather than in a separate static presentation block.


## V6.8 High-Impact Rhythm Extension
For combat-led short videos, keep the heat curve biased toward active exchange. Default tactical pause soft maximum is 2.0s; pauses above 2.5s require explicit tactical, charging or result-observation justification. Important impact anchors should generally recur every 2–4s, subject to action duration and model feasibility.

Use micro-recovery to reset spacing, breath, weapon position or tactical information without converting the video into a static character showcase.
