# Shot Coverage Graph — 6.4

Map physical events to observing shots.

Every critical physical event must have at least one valid observing shot unless explicitly marked off-screen by design. A shot may observe multiple events only when temporal/spatial readability remains valid.

Detect:
- unobserved critical event
- duplicated physical event
- contradictory observation
- impossible handoff

Coverage is a QA graph, not a source of physical truth.
