# Model Capability Feedback Runtime — 6.5

Model capability constraints may influence representation complexity, never canonical combat semantics.

## Feedback loop
`CAPABILITY PROFILE → COMPLEXITY CHECK → REPRESENTATION ADJUSTMENT → SEMANTIC HASH CHECK → PROMPT COMPILATION`

Allowed changes: shot density, camera complexity, wording density, effect layering, grouping of non-critical observations.

Forbidden changes: actor identity, action order, tactical reason, contact result, damage result, event identity, ending state, hard constraints.

If simplification cannot preserve required semantics, escalate rather than silently degrade the event.
