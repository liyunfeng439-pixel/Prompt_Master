# Motion Transfer Contract — 6.4

Reference motion transfer has three classes.

### Preserve
motion intent, event order, relative timing, acceleration pattern, contact logic, weight transfer, recovery logic, tactical purpose.

### Adaptable
amplitude, body posture, weapon interpretation, camera framing, VFX, scale and world-specific physics expression.

### Immutable
user hard constraints, target identity, required outcome, prohibited behavior and explicit ending constraints.

A transfer fails if adaptation changes a preserved semantic event or violates immutable canon.
