# Repair Escalation V2

Repair only the lowest causal layer that can resolve the failure.

L1 parameter → L2 action → L3 state → L4 space → L5 canon/clarification.

Additional rule: if a failure originates from uncertainty, resolve or propagate uncertainty before changing downstream behavior.

Never use camera, VFX, audio, prompt wording, or model-adapter changes to conceal an upstream feasibility or continuity failure.
