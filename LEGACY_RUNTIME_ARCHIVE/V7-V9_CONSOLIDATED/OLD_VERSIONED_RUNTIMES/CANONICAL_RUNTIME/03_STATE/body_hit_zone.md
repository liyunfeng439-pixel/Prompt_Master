# Body / Equipment Hit-Zone Runtime — 6.4

Standard zones: HEAD, NECK, TORSO, SHOULDER, ARM, ELBOW, HAND, HIP, THIGH, KNEE, CALF, FOOT, WEAPON, ARMOR, OTHER.

Hit zone modifies reaction, damage, mobility, weapon control and future action availability only when supported by the character model and impact logic.

Example: a confirmed right-hand disabling injury can invalidate or degrade actions requiring right-hand control until an explicit recovery event.
