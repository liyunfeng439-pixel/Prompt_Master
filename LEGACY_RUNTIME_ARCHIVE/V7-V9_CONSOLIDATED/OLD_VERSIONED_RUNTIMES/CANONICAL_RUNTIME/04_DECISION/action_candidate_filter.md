# Action Candidate Filter — 6.4

Filter retrieved actions in this order:
1. immutable canon
2. actor capability and injury
3. weapon availability
4. spatial reach / geometry
5. temporal prerequisites
6. resource / ability availability
7. tactical relevance
8. continuity compatibility
9. model/shot complexity budget

Any hard failure removes the candidate. UNKNOWN may remain only when the uncertainty does not create a hard contradiction; otherwise escalate.
