# Reaction Selection Runtime — 6.4

Choose defense/reaction from observable trigger, actor perception, available body/weapon state, distance, incoming trajectory and tactical objective.

Valid reactions include BLOCK, DEFLECT, EVADE, ABSORB, RETREAT, COUNTER, INTERRUPT, GRAPPLE, DISARM, REPOSITION, PURSUE, MISS.

A reaction cannot be selected merely because it is visually convenient; it must be physically and temporally reachable from the observed state.
