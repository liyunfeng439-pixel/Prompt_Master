# Tactical Causal Graph — 6.3.1

`CAUSE → PERCEPTION → TACTICAL_REASON → ACTION_INTENT → TEMPORAL_BEAT → CONTACT/OUTCOME → CONSEQUENCE → NEW_STATE → NEXT_DECISION`

Every major attack records actor_id, observed_state, tactical_goal, constraints, selected_action, expected_response, alternatives, selection_reason and resulting_state.

Defense/reaction requires an observable trigger. Counter requires a grounded opening, commitment, miss, imbalance or equivalent opportunity.

The graph and temporal state machine are two views of the same event chain: tactical reasoning explains **why**; temporal state explains **when/how it executes**. They must reference the same event/beat identifiers rather than duplicating independent actions.
