# Actor Decision / Reaction Loop

ACTOR A DECISION → ACTION → OBSERVATION → ACTOR B RESPONSE → NEW STATE → ACTOR A NEXT DECISION

Responses: BLOCK / DEFLECT / EVADE / ABSORB / RETREAT / COUNTER / INTERRUPT / GRAPPLE / DISARM / REPOSITION / PURSUE / MISS.

Responses are selected from current spatial, temporal, weapon and damage state and must preserve actor-specific style. Avoid scripted turn-taking.
