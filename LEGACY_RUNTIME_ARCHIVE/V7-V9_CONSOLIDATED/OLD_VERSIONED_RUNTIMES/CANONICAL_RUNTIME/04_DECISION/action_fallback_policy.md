# Action Fallback Policy — 6.4

When no candidate survives:
L1 reduce amplitude/complexity while preserving tactical intent;
L2 choose a simpler compatible action from the same action family;
L3 adjust timing or position only if allowed by canon and state;
L4 re-query after state repair;
L5 request clarification when a hard unknown blocks execution.

Never invent a novel hard fact merely to keep the sequence moving.
