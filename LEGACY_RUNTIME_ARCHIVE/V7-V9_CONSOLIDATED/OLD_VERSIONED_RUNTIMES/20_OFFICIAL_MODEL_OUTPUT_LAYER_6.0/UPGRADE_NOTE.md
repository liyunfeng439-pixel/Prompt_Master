
# Layer 6.0 Upgrade

Problem fixed:
Layer 5 generated native adapters, but final output was not separated as official-style model formats.

Changes:
- Added Official Model Output Layer.
- Seedance 2.5 output now uses Reference -> Brief -> Timeline -> Motion -> Physics -> Ending structure.
- MiniMax H3 output now uses Scene -> Characters -> Action Sequence -> Camera -> Effects -> Consistency structure.
- Existing Combat Intelligence remains unchanged.

Note:
Templates are integrated production formats based on publicly described model prompting practices, not claims of proprietary hidden schemas.
