# V10.1.0 Consolidation Upgrade

1. Unified SKILL metadata and title to V10.1.0.
2. Established one canonical current runtime: CANONICAL_RUNTIME_V10.1.
3. Converted V9.9/V9.9.5/V9.9.8 current-runtime files into compatibility stubs and archived their originals.
4. Promoted 30-second Shot Budget to a V10.1 contract: target 7, soft minimum 6, hard maximum 7.
5. Explicitly separated Beat Auto-Split from final Shot allocation.
6. Introduced SHOT_IR V10.1 as the only semantic input to model adapters.
7. Introduced a single Native Output Router with independent Universal, Seedance 2.5 and MiniMax H3 adapters.
8. Removed the implication that Skill-defined templates are vendor-internal official formats; adapter docs are now explicitly Skill-native compilation contracts.
9. Added regression rules for version governance, shot budget and adapter invariants.
10. No combat core, VFX, physics, continuity, damage or ending intelligence was removed.
