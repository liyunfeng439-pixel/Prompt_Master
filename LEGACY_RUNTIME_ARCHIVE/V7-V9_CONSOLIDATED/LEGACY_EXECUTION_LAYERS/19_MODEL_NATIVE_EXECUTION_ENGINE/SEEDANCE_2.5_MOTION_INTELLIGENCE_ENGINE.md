
# Seedance 2.5 Motion Intelligence Engine

Purpose:
Convert cinematic combat descriptions into motion-readable generation prompts.

Required fields:

- Character state
- Attack intent
- Motion vector
- Body mechanics
- Weapon physics
- Cloth and hair follow-through
- Camera movement
- Impact result
- Next state transition

Combat rules:
Every attack:
Preparation -> Acceleration -> Contact -> Physical Result -> Recovery
