- 云疏影: weapon = 凌云长枪; Qingyun immortal-sect visual; white/ice-blue costume palette.

## Required gates
1. Weapon Integrity must pass for sword and spear actions.
2. V4 action candidates must resolve into ACTION_EXECUTION_CONTRACT.

4. 法相 escalation must resolve through ABILITY_EXECUTION_CONTRACT.

6. Default 30s budget must remain ≤7 final shots.

## Expected ending state
`云疏影 = defeated + retreating/escaped`
`小白龙 = victorious + stationary/withdrawn weapon + NO_CHASE`
