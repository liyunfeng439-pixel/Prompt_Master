```yaml
  distance_model: ...

ability_contract:

source_trace:
  knowledge_file: ...

```

## Hard invariants
1. `pre_state` must be compatible with current MASTER_COMBAT_STATE.
2. `result` must be causally produced by `execution`.
3. `opponent_response` must produce the target state used by the next decision.
4. `recovery.output_state` becomes the next attacker state unless a result explicitly overrides it.
5. `transition` must be validated before Beat Graph insertion.
6. Camera/VFX/environment are presentation bindings and cannot alter physical facts.


## V10.9.0 Integrity invariants
7. `weapon_control.weapon_identity` must equal Canon and action weapon identity.
8. `weapon_integrity.result` must be `PASS` or `REPAIRED_PASS` before execution.
9. A persistent/escalation ability must reference `ability_contract.ability_contract_id` before Beat Graph insertion.
